# 语法

1. Number list

   ```
   1. + Space
   ```

2. Bullet list

   ```
   - + Space
   ```

3. Toggle list

   ```
   + + Space
   ```

   ```
   + 项目 A
     123
   
   + 项目 B
     123
   
   + 项目 C
     123
   ```

   注意：`- [ ]` 是 Todo List，不是 Toggle list。
   
4. Todo List

   ```
   - [ ] + Space	
   ```

5. Divider

   ```
   ---
   ```

6. Quote

   ```
   " + Space
   ```

7. Heading

```
# + Space， Heading 1
## + Space，Heading 2
### + Space，Heading 3
#### + Space，Heading 4
##### + Space，Heading 5
###### + Space，Heading 6
```

8. Toggle list Heading 暂停使用

   ```
   + # Heading 1
   <空行>
   SapceSpace<Text：Tex是折叠的正文>
   ```
